	Задача:                                    Метод:           URL:					    

1. Получение всех отделов                            GET    /departments?page={Номер текущей страницы}&recordsPerPage={Кол-во записей на странице}
2. Добавление сотрудника в отдел 		     POST   /employees
3. Получение всех сотрудников отдела                 GET    /departments/sale?page={Номер текущей страницы}&recordsPerPage={Кол-во записей на странице}
4. Сделать сотрудника менеджером отдела              PATCH  /employees/manager/${id}
5. Изменение существующей информации о сотруднике    PUT    /employees/${id}
6. Удаление сотрудника из отдела                     DELETE /employees/${id}
